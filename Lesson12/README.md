## What I Learned

- Functions allow me to write reusable code.
- Parameters receive values when a function is called.
- Arguments are the actual values passed to parameters.
- The `return` statement sends a value back to the caller.
- Local variables exist only inside a function.
- Global variables can be accessed outside a function.
- Docstrings explain what a function does.
