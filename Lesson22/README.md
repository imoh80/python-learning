# Lesson 22 - Sets

## Overview

This lesson introduces Python sets. A set is an unordered collection of unique elements. Sets automatically remove duplicate values and are useful for membership testing and mathematical set operations.

---

## Topics Covered

- Creating sets
- Empty sets
- Duplicate removal
- Membership testing (`in`, `not in`)
- Union (`|`)
- Intersection (`&`)
- Difference (`-`)
- Adding elements with `.add()`
- Adding multiple elements with `.update()`

---

## Files

### set_creation.py
Demonstrates how to create sets, remove duplicates automatically, and create an empty set.

### membership_testing.py
Shows how to check whether an item exists in a set using `in` and `not in`.

### set_operations.py
Demonstrates union, intersection, and difference operations.

### add_update.py
Shows how to add one item using `.add()` and multiple items using `.update()`.

### mini_project.py
A simple inventory manager that compares available and required skills using set operations.

---

## Key Takeaways

- Sets are unordered.
- Sets do not allow duplicates.
- Sets cannot be indexed.
- Use `in` for fast membership testing.
- Use `|`, `&`, and `-` for set operations.
- Use `.add()` to add one item.
- Use `.update()` to add multiple items.
