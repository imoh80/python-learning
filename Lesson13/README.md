# Lesson 13 - Functions and Parameters

## Overview

In this lesson, I learned how to create functions with multiple parameters and how to pass values using positional, keyword, and default arguments. I also learned the rules for mixing positional and keyword arguments correctly.

## Files

- `parameters.py` - Functions with multiple parameters.
- `positional_arguments.py` - Passing arguments by position.
- `keyword_arguments.py` - Passing arguments using parameter names.
- `default_parameters.py` - Using default parameter values.
- `mini_project.py` - Coffee shop receipt generator using functions and parameters.
