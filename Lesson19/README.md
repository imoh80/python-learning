# Lesson 19 - Lists: Methods and Mutability

## Overview

In this lesson, I learned that Python lists are mutable, meaning they can be modified after they are created. I also learned how to add, remove, update, and sort items using built-in list methods.

## Files

- `mutability.py` - Demonstrates how to modify items in a list.
- `list_methods.py` - Demonstrates the use of `append()`, `pop()`, and `remove()`.
- `sorting.py` - Demonstrates how to sort lists using the `sort()` method.
- `mini_project.py` - A simple coffee shop inventory management program using list methods.
