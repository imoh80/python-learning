# Lesson 17 - Recursion

## Overview

In this lesson, I learned about recursion in Python. A recursive function is a function that calls itself to solve a smaller version of a problem. I also learned the importance of having a base case to stop the recursion and a recursive case that moves the function closer to the base case.

## Files

- `recursion_basics.py` - Demonstrates a simple recursive countdown.
- `base_case.py` - Shows why every recursive function needs a base case.
- `call_stack.py` - Demonstrates how the call stack works during recursion.
- `mini_project.py` - A simple recursive countdown timer.
