# Lesson 18 - Lists

## Overview

In this lesson, I learned about Python lists and how they are used to store multiple values in a single variable. I also learned how to access items using positive and negative indexing, retrieve multiple items using slicing, and understand common errors like `IndexError`.

## Files

- `list_creation.py` - Creating lists and accessing their data type.
- `indexing.py` - Demonstrates positive and negative indexing.
- `slicing.py` - Demonstrates list slicing.
- `mini_project.py` - A simple coffee shop menu program using lists.
