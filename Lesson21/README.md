# Lesson 21: Dictionaries

## Overview

This lesson introduces Python dictionaries. A dictionary stores data as key-value pairs, making it easy to organize and retrieve information.

Example:

```python
student = {
    "name": "Mary",
    "course": "AI Engineering",
    "level": "Beginner"
}
```

Unlike lists, dictionaries use keys instead of index positions.

## Key Takeaways

- Dictionaries store information as key-value pairs.
- Keys are unique.
- Values are accessed using their keys.
- `.get()` safely retrieves values without crashing.
- Dictionaries are mutable.
