# Lesson 15 - Higher-Order Functions

## Overview

In this lesson, I learned how to use higher-order functions in Python. I explored lambda functions for creating simple anonymous functions, used `map()` to transform data, `filter()` to select items based on a condition, and `sorted()` to organize data.

## Files

- `lambda_functions.py` - Creating and using lambda functions.
- `map_function.py` - Applying a function to every item in a list with `map()`.
- `filter_function.py` - Filtering items from a list using `filter()`.
- `sorted_function.py` - Sorting lists and dictionaries using `sorted()`.
- `mini_project.py` - A coffee shop menu project demonstrating lambda, map, filter, and sorted together.
