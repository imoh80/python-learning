# Lesson 16 - Anonymous Functions (Lambda)

## Overview

In this lesson, I learned about anonymous functions (lambda functions). I learned how lambda functions differ from regular functions, how they automatically return values without using the `return` keyword, and why they are useful for short, one-time operations.

## Files

- `lambda_basics.py` - Creating lambda functions and comparing them with regular functions.
- `implicit_return.py` - Demonstrates that lambda functions return values automatically.
- `single_expression.py` - Shows that lambda functions are limited to a single expression.
- `mini_project.py` - Uses lambda functions to calculate discounts on coffee prices.
