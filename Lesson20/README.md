# Lesson 20: Tuples

## Overview
This lesson introduces tuples in Python. Tuples are ordered collections that cannot be modified after they are created. They are useful for storing data that should remain constant throughout a program.

## Topics Covered
- Creating tuples
- Single-item tuples
- Tuple indexing
- Tuple methods (`count()` and `index()`)
- Immutability
- Tuple unpacking

## Key Takeaway
Use tuples when your data should remain unchanged. They are lightweight, memory efficient, and protect important data from accidental modification.
