# Lesson 14 - Function Scope and Lifetime

## Overview

In this lesson, I learned how Python manages the visibility and lifetime of variables. I explored local and global scope, how to modify global and enclosing variables using the `global` and `nonlocal` keywords, and how Python searches for variables using the LEGB rule.

## Files

- `local_scope.py` - Understanding local variables and their scope.
- `global_scope.py` - Reading global variables inside functions.
- `global_keyword.py` - Modifying global variables using the `global` keyword.
- `variable_lifetime.py` - Understanding the lifetime of local and global variables.
- `nonlocal_keyword.py` - Modifying variables in an enclosing function.
- `mini_project.py` - Demonstrates local scope, global scope, and variable lifetime together.
